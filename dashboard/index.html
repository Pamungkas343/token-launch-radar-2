How the value is built

implied value = TVL × category multiple × growth × maturity

The multiple is the median market-cap / TVL of the live-token protocols in the same category (at least 3 samples), otherwise the global median. Growth is half-weighted 7-day TVL change, clamped. Maturity rewards time listed, capped at three years. Nothing here predicts that a token will launch — it ranks what one would be worth if it did.
